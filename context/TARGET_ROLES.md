# Target Roles

## Priority A — Primary targets

- AI Engineer
- Agentic AI Engineer
- Applied AI Engineer
- LLM Engineer
- Generative AI Engineer
- AI Application Engineer
- AI/ML Engineer where the role includes production ML or GenAI systems

## Priority B — Strong adjacent roles

- Machine Learning Engineer
- Data Scientist focused on production ML systems
- NLP Engineer
- AI Platform Engineer at junior/medior level
- ML Platform / MLOps roles when they remain hands-on with ML systems

## Priority C — Domain-specialist opportunities

- Biomedical AI Engineer
- Bioinformatics ML Engineer
- Computational Biology / ML roles
- Drug Discovery AI
- Knowledge Graph / Graph ML roles
- Cheminformatics-adjacent AI roles when the skill gap is realistically bridgeable

## Preferred technical themes

Strong positive signals:
- RAG
- LLM evaluation
- Agentic workflows
- Multi-agent systems
- Model orchestration
- Guardrails / hallucination mitigation
- Production AI systems
- FastAPI / Python backend
- Cloud deployment
- ML systems
- Knowledge graphs
- Graph ML
- Healthcare / life sciences AI

## Low-priority or excluded categories

Exclude by default:
- Business Intelligence Analyst
- Data Analyst
- Generic frontend engineering
- Generic backend engineering with no AI/ML focus
- Pure prompt-engineering jobs with little engineering depth
- Pure research roles requiring a PhD unless the fit is unusually strong
- Principal / Staff / Lead positions clearly requiring extensive leadership history
